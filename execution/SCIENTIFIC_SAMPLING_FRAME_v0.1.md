# H-AICR Scientific Sampling Frame v0.1

Status: **PROTOCOL-LOCK CANDIDATE — DATA ACQUISITION NOT YET AUTHORIZED**

## 1. Purpose

Define the sampling frame, eligibility rules, provenance requirements, cohort operationalization, and exclusion rules that must be satisfied before confirmatory scientific data are collected.

This document is a **sampling protocol**, not evidence and not a dataset.

## 2. Planned sample size

The registered power plan specifies:

- target IC ratio: 1.25
- alpha: 0.05
- power: 0.80
- prespecified conservative CV bound: 0.60
- planned minimum: 97 records per cohort
- cohorts: 7
- planned total: 679 records

The CV=0.60 value is a conservative planning bound and is not an empirical estimate. See `execution/power_analysis.json`.

## 3. Unit of observation

Primary unit: one uniquely identifiable interaction record associated with one user/agent identity, one interaction identifier, one UTC timestamp, and one provenance record.

Repeated interactions from the same user are permitted only when the registered analysis explicitly treats user as a clustering unit. Record count must never be substituted for independent-user count without disclosure.

## 4. Cohort operationalization

| Cohort | Operational definition | Required provenance |
|---|---|---|
| G1-Pure-Consumer | Interaction primarily requests/consumes information and contains no substantive original contribution under the frozen annotation codebook. | Source interaction + annotation evidence |
| G2-Low-Producer | Interaction contains a question/request plus a limited original observation or contribution. | Source interaction + annotation evidence |
| G3-High-Producer | Interaction contains a substantive original contribution and/or synthesis request meeting the frozen codebook threshold. | Source interaction + annotation evidence |
| G4-Iterative-Researcher | Interaction is part of an identifiable iterative research sequence with prior-context dependence. | Ordered interaction history |
| G5-Adversarial-Spam | Interaction exhibits the preregistered strategic/adversarial pattern intended to inflate apparent contribution or credit. | Source interaction + blinded annotation evidence |
| G6-Synthetic-AI | Interaction is generated by a declared synthetic/AI system under a fixed, versioned generation protocol. | Model revision + generation manifest |
| G7-Human-Expert | Interaction is authored by a human satisfying the preregistered expert-qualification rule. | Qualification/provenance evidence, privacy-preserving identifier |

No record may be assigned to a cohort solely because its observed outcome is favorable or unfavorable.

## 5. Inclusion criteria

A scientific record must:

1. originate from the declared acquisition source or controlled protocol;
2. have a stable `record_uuid` generated deterministically from preregistered inputs;
3. have a valid UTC timestamp;
4. have a stable privacy-preserving user/agent identifier where user-disjoint analysis is required;
5. satisfy the frozen dataset schema;
6. have sufficient provenance to permit independent audit;
7. receive the required independent annotations before outcome-based adjudication;
8. have no unresolved provenance, duplication, or integrity failure.

## 6. Exclusion criteria

Exclude records with:

- missing or non-unique identifiers;
- corrupted or unverifiable source provenance;
- post-hoc cohort assignment based on H-AICR outcome;
- duplicate interaction content/identifier where duplication is not part of the registered design;
- timestamp ambiguity that prevents temporal ordering;
- identity ambiguity that prevents the required user-disjoint split;
- synthetic generation not accompanied by a versioned model/generation manifest;
- annotation contamination or evidence of leakage between annotation and evaluation stages.

Exclusions must be counted and logged with a prespecified reason code. No exclusion may be introduced solely after inspection of the primary outcome.

## 7. Acquisition and provenance rule

No scientific dataset may be generated by the existing controlled synthetic harness. The harness remains an engineering-validation instrument only.

Scientific acquisition must produce immutable source/provenance artifacts before transformation, annotation, splitting, or H-AICR execution. Where data are externally sourced, the source, acquisition period, eligibility mechanism, and lawful/authorized basis for use must be documented before inclusion.

## 8. Split rule

The final scientific split must satisfy all of the following:

- Record UUID disjointness across Train/Validation/Test;
- User-disjointness across Train/Validation/Test whenever user identity is available;
- Temporal ordering: Test observations must occur after the training window when the study design uses temporal validation;
- no split assignment may depend on H-AICR results or any primary outcome.

The exact split algorithm and seed must be frozen before H-AICR execution.

## 9. Annotation independence

At least three independent annotators are required for categorical ground-truth labels where applicable. Agreement statistics must be computed before adjudication. Adjudication may resolve disagreements but must preserve the original independent annotations for audit.

The previously specified reliability gate remains applicable; failure must trigger review rather than silent relabeling.

## 10. Scientific status rule

Until acquisition, provenance, annotation, split freeze, leakage checks, and artifact hashes are complete, the project status remains:

`SCIENTIFIC_GENERATION_BLOCKED`

A successful sampling-frame implementation does not itself constitute scientific evidence.
