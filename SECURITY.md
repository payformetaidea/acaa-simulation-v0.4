# Security Policy

## Supported version

The validated v0.4 baseline is maintained as a research and experimental artifact.

## Reporting a security issue

Please report suspected security vulnerabilities privately to:

**Pouria Valaee**  
pouria@pouriavalaee.ir

Please do not disclose exploitable details publicly before a coordinated assessment has been completed.

## Scope

Reports may include vulnerabilities in repository automation, dependency handling, artifact integrity, workflow permissions, or code paths that could compromise the integrity of validation evidence.
